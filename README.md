# Brew Haven ☕

A responsive coffee shop website built using HTML, CSS, and JavaScript.

## Features

- Responsive design
- Smooth navigation
- Dynamic menu expansion
- Table reservation form
- Local storage booking system
- Modern UI design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Preview

Brew Haven is a modern coffee shop landing page showcasing menu items, gallery, customer reviews, and table reservations.
